# 主动开口：让别人替她开口的那一端

海螺这边只做一件事：**收到「她想找人说句话」，就用她自己的嘴说一句。**

为什么不让插件自己发：人设、对话历史、语气都在海螺这里。
别家自己发只能拼模板句，而且那句不在她的历史里——你回一句「啥？」，她接不上。

对外契约与 Tide 无关，任何插件都能接（汐/心情插件是目前唯一在用的）：
完整字段、回执语义、时序图见汐仓库的 `docs/主动消息-对接.md`。

---

## 端点

```
POST http://127.0.0.1:7801/api/proactive/say
x-console-token: <panel.token>

{
  "event_id": "t1793000000-a1b2c3",     # 这一次的唯一号（回执原样带回）
  "why": "想你 91",                      # 为什么想开口，会写进提示词
  "urgency": 87.4,                       # 可选
  "needs": {...},                        # 可选，仅供参考
  "person": "主人",                      # 可选
  "conv_id": "private:10000",            # 可选，不给就用配置里的
  "report_url": "http://127.0.0.1:7880/api/proactive-report"
}

→ {"ok": true, "accepted": true, "conv_id": "private:10000"}
→ {"ok": false, "error": "..."}
```

- 立刻返回，真说话在后台（跑一次模型几秒，别让上游超时掐掉）
- 说完主动往 `report_url` 回执：`{"event_id", "sent": true|false, "text", "error"}`
- **失败如实回 sent=false**（模型没说话 / 被闸拦 / OneBot 报错都算失败）

## 她怎么说话

走的是她平时那条链路，不是另开一套：

```
system_prompt（人设）+ 词库 + 语言提示
  → speech.prompt（心情插件把「你现在的心情」写进去）
  → 模型（带工具，跟平时一样）
  → speech.gate（别的插件还能拦，拦了就算失败）
  → send_lines（分条、语音、表情都照旧）
  → 写进聊天记录 + 记忆库 + 用量账本（feature=proactive）
```

那句提示词在这里：`plugins/conch/main.py` 的 `PROACTIVE_NUDGE`
（「这会儿没人跟你说话，是你自己想起来找他……」）。

## 配置

```json
"proactive": {
  "enabled": true,                      // 总开关；默认关，得自己打开
  "conv_id": "private:3102849732",       // 发给谁；不给就用第一个称呼卡的私聊
  "report_url": "http://127.0.0.1:7880/api/proactive-report",
  "report_timeout_sec": 8
}
```

关掉（`enabled: false`）时端点直接拒绝，调用方会记一笔「宿主没收」并退避 ——
不会变成反复重试。

## 谁在用它

- 汐（Tide）：想念/无聊越过门槛 → 通知这里 → 她说一句 → 回执 → 汐闭麦进冷却
- 冷却、每天上限、免打扰都在汐那边，海螺不重复一套
