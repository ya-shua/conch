# 她的声音（2026-11-10）

一条语音从"她想说"到"你听到"，中间经过四个人，各自的活儿不许越界：

```
汐 → 海螺 → 声来 → 海螺 → QQ
心情      说话      合成      发送
```

## 谁负责什么

| 谁 | 干什么 | 不干什么 |
|---|---|---|
| 汐（tide/mood） | 算出这一句该用的语速、音高、语气 | 不合成、不发送 |
| 海螺 | 决定要不要说、说什么；把心情带进合成参数；**发出去** | 不做声音本身 |
| 声来 | 文本 + 音色 + 参数 → 一个音频文件 | 不知道发给谁，也不该知道 |

**发送这一下归海螺**，理由很实在：conv_id 只有海螺手上；重试和日志都已经在
`send_voice` 里；声来再去连一次协议端，只是多一处会坏的地方。

## 心情怎么进声音

汐的 `plan_reply()` 已经算好了结构化参数（`汐/tide/core.py` L999）：

```python
{"tone": …, "voice": {"instruct": "语速偏快，句尾上扬", "speed": 1.06, "pitch": 2}}
```

`instruct` 是给 TTS 的语气描述，`speed` 是倍率，`pitch` 是**半音**。
汐的插件把它挂在 `payload["plan"]["voice"]` 上（`plugins/mood/main.py` L147），
跟着 `speech.prompt` 一起过来。

海螺以前只取了 `payload["extra"]` 那段文字，三个值当场就丢了 —— **这就是
"情绪有了、声音有了，但生成不了有情绪的声音"的根因**（另一半原因是声来
自己去找汐的路径 `D:/AI/*/tide`，而汐早就搬到插件目录了，`_tide_voice()`
一直返回空字典）。

现在（`plugins/conch/main.py`）：

1. `ask_prompt_extra` 顺手 `_CURRENT_VOICE.set(plan["voice"])`
2. 她调 `voice_speak` 时，`mood_voice_args()` 自动补：
   - `rate` = `speed`
   - `pitch` = `2 ** (半音 / 12)`（声来的 pitch 是乘数，汐给的是半音）
   - `style` = `instruct`
3. 她自己给了 `rate/pitch/style/emotion` 就用她的，不覆盖；
   给了 `emotion` 就不塞 `style`（声来里 emotion 会盖掉 style）

**她不需要挑"情绪档"**：她说这句话时是什么心情，声音就是什么心情。
想刻意撒娇才显式给 `emotion`。

## 文件怎么认

声来的返回里有两行路径（`文件:` 是给人看的，`AUDIO:` 是给程序看的）：

```
✅ 说话完成（音色「龙婉·小米 MiMo TTS」）
文件: D:\AI\声音工坊\outputs\龙婉·小米 MiMo TTS_20261110_012631.wav
AUDIO: D:\AI\声音工坊\outputs\龙婉·小米 MiMo TTS_20261110_012631.wav
大小 225 KB · 格式 wav
```

海螺按**整行**取（`audio_path_of`），不做正则猜路径。旧正则 `[^\s"'<>|]+`
不认空格，而产出文件名里有 `龙婉·小米 MiMo TTS_…` —— 在空格处截断，
于是报"没拿到音频文件"。空格、`·`、中文现在都不会断。

## 成没成，她知道的是真话

`deliver_audio()` 发完把工具结果改写掉：

- 成功 → `（海螺已经把它发成一条语音了，对方听得到。）`
- 失败 → `（海螺发语音失败了，没发出去。别跟人说你发了。）`
- 不知道发给谁 → `（海螺不知道该把这条语音发给谁，所以没发出去。）`

路径不回她的上下文，免得她再抄一遍。以前那句
"把上面的文件路径发给用户即可播放"就是病根：模型读完以为自己给过了。
