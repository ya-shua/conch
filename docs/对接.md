# 海螺 · 对接说明（宿主这一侧）

海螺是**宿主**：它自己是一张嘴和一对耳朵，别的插件通过它说话、看东西、记事情。
所以这份文档回答两个方向的「怎么接」：

- **插件 → 海螺**：我写了个东西，怎么让海螺用上它？
- **外部 → 海螺**：我想让海螺说句话 / 查它状态，怎么调？

## 一、插件 → 海螺（三条路，按需选）

| 你的东西是什么 | 接法 | 看哪份文档 |
|---|---|---|
| 只是「让她能多做一件事」 | 写个插件包放进 `plugins/<id>/`，实现 `setup(ctx)` | [plugin-tools.md](plugin-tools.md) |
| 有独立面板/进程（像留影、声来） | 给仓库放 `metadata.json`（launch/port/url），宿主就能一键启停 | [plugin-launch.md](plugin-launch.md) |
| 想让海螺替你说话（判断在你、嘴在她） | `POST /api/proactive/say`，再回报结果 | [主动开口.md](主动开口.md) |

插件包的四个必填东西（`metadata.json` / `/api/health` / `/api/manifest` / `docs/对接.md`）
和字段级规则写在 [插件对接契约.md](插件对接契约.md)。

三条硬规矩：

1. **失败要如实说**。返回 `{"ok": false, "sent": false, "error": "..."}`，不许静默成功 ——
   汐那边的冷却、好感、缓解全靠这个布尔值。
2. **别自己另外起一套 QQ**。发消息一律走宿主的 `ctx.services`，不然一个号会被两个进程抢。
3. **别改宿主的账**。你今天说了几句、花了多少 token，宿主自己记；插件只回报结果。

## 二、外部 → 海螺（HTTP）

面板端口默认 `7801`。除 `/`、`/ping.js`、`/api/health`、`/api/manifest` 外，
都要 `x-console-token`（`config.json` 里 `panel.token`）。

| 想干的事 | 怎么调 |
|---|---|
| 探活 | `GET /api/health` |
| 我是谁 / 有什么能力 | `GET /api/manifest` |
| 整体状态（连着没、花了多少） | `GET /api/status` |
| 让海螺说一句 | `POST /api/proactive/say`（见下） |
| 插件列表 / 启停 / 重载 | `GET /api/plugins`、`POST /api/plugins/{id}/toggle` |
| 记忆、日志、用量 | `GET /api/messages`、`/api/logs`、`/api/usage/summary` |

`POST /api/proactive/say` 的请求体和回报语义在 [主动开口.md](主动开口.md)；
汐那边（发起方）的说明在 `汐/docs/主动消息-对接.md`。

## 三、能力清单

- 说话：人格卡 + 称呼 + 表情包 + 语音
- 加载 / 启停 / 重载插件，给它们提供 `services`
- 替插件主动开口（`/api/proactive/say`）
- 记忆与用量统计
- 面板与设置（7801）

## 四、失败语义

| 情况 | 返回 | 调用方怎么做 |
|---|---|---|
| 没设密码 | 直接放行 | — |
| 设了密码但没带令牌 | `401 {"need_login": true}` | 带 `x-console-token` |
| 非 JSON body 的写请求 | `403 content-type must be application/json` | 改 body |
| Host 头不是本机 | `403 bad host` | 别绕过 |
| 模型没配 / 调不通 | 动作返回 `ok: false` + 原因 | 别当成功；插件侧要能降级 |

**不可逆动作**：发消息（`/api/proactive/say`）、清记忆（`/api/messages/clear`）——两者都会真实发生，别拿它们试接口。

## 五、单独运行

```powershell
cd <插件目录>
.\.venv\Scripts\python.exe main.py --config config.json
```

需要：一个 OneBot 实现（SnowLuma，`127.0.0.1:3000/3001`）+ 已登录的 QQ + 模型 key。
不带插件也能跑：面板能开、消息能收发、只是没有额外能力。

## 六、自检

```powershell
curl http://127.0.0.1:7801/api/health
curl http://127.0.0.1:7801/api/manifest
curl -H "x-console-token: dev-token" http://127.0.0.1:7801/api/status
```
