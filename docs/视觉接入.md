# 视觉接入：换别的看图插件也不用改代码

海螺自己不绑定哪一家视觉模型。它只看一个东西：**谁能按约定给出一句描述（和可选标签）**。
所以留影、智谱直连、你自己写的小脚本、甚至别人插件的 HTTP 服务，都能接进来。

设置位置：面板 → 表情包 → 设置 → 聊天看图 → **看图走哪边**。

## 五种取值

| 取值 | 说明 |
|---|---|
| `auto`（默认） | 依次挑：留影在 → 留影；配了自定义命令 → 命令；配了接口 → 接口；有 Key → 直连 |
| `plugin` | 只用留影（`bridge/eye.mjs`，需要 `look.eye_root` 指向留影项目） |
| `direct` | 海螺直连 OpenAI 兼容的视觉模型，用面板里的地址 / 模型名 / Key |
| `cmd` | 跑一条外部命令，从 stdout 最后一行读 JSON |
| `http` | POST 到一个接口，读它的 JSON |

## 自定义命令的约定

面板里填：`python D:\vision\look.py`（带空格的路径请用引号包起来）。

海螺调用它时：

```
python D:\vision\look.py <图片路径或图链>
```

环境变量也会带上：

| 变量 | 值 |
|---|---|
| `CONCH_IMAGE` | 图片路径或图链（同最后一个参数） |
| `CONCH_KIND` | `chat`（聊天看图）或 `sticker`（表情包识别） |
| `CONCH_GUIDANCE` | 表情包那边人写的说法，可能为空 |
| `EYE_TIMEOUT_MS` | 这次允许多久（毫秒） |

**输出**：stdout 最后一行是一个 JSON 对象，别的行随便打日志。

```json
{"desc": "一只猫四脚朝天躺着", "tags": ["摆烂", "累"]}
```

字段只有 `desc` 是必须的：

| 字段 | 说明 |
|---|---|
| `desc` / `text` / `content` / `meaning` | 描述，任一个都认，优先 `desc` |
| `tags` / `labels` | 标签，数组或「猫、可爱」这种顿号字符串都行，最多取 5 个 |
| `points` | 可选，2–4 条要点（聊天看图会拼进提示词） |
| `model` | 可选，记日志用 |
| `ok` | 写了 `false` 视为失败；不写当成功 |

## 自定义接口的约定

面板里填：`http://127.0.0.1:9100/see`。

海螺发 `POST`，body：

```json
{"image": "D:\\...\\a.jpg 或 https://...", "kind": "chat", "guidance": ""}
```

返回 JSON，字段同上（`desc` 必须，`tags` 可选）。HTTP 状态 ≥ 400 视为这次失败。

## 失败怎么算

- 命令超时、非零退出且没有 JSON、`ok:false`、接口 4xx/5xx —— 都算「这次没看成」
- 聊天看图：当没看见，不写进提示词
- 表情包：进缓冲区，按 1 / 5 / 20 分钟退避重试（次数在设置里）
- 不管哪条路，每天都算一次额度（同一张图当天只算一次）
