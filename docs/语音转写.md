# 语音转写（她能"听"语音）

> 2026-11-09。目标不是"把语音存成文件"，是**让她听懂语音、照常回话**，而且不能因为转错字把意思带偏。

## 一条语音的完整链路

```
QQ 语音（silk）
  ↓ 1. 取文件：record 段里的 url 直接下（本地有路径就用本地）
  ↓ 2. silk → 16k 单声道 PCM（tools/silk_decode.cjs + vendor/silk-wasm，纯 wasm）
  ↓ 3. 套 wav 头（16bit/16k/单声道），不额外转码
  ↓ 4. POST {baseUrl}/audio/transcriptions（OpenAI 兼容，multipart）
  ↓ 5. 文本按 `[语音转写] …` 塞进上下文
  ↓ 6. 她照常理解、照常回；记忆库另记一份
```

## 为什么自己解 silk

- QQ 语音实际格式是 **silk**，而且文件头前面还挂着一个 `0x02` 字节。
- **ffmpeg 解不了 silk**，`get_record` 传 `out_format=mp3/wav` 返回的仍是原 silk 文件（实测）。
- `pilk` 需要编译工具链，装不上。
- 所以用 `silk-wasm`（npm 包，MIT，纯 wasm，无需编译）解成 PCM，自己套 wav 头。
  - 解码器：`plugins/conch/tools/silk_decode.cjs`
  - 依赖：`plugins/conch/vendor/silk-wasm/`（跟仓库一起走，不用 npm install）
  - node 从 `config.json` 的 `look.node` 找，其次 PATH、`C:\Program Files\nodejs\node.exe`

## ASR 用哪家

- 跟「留影」插件借配置：`留影/data/vision.json` 的 `asr` 段
  （`baseUrl` / `model` / `apiKey`，默认硅基流动 `FunAudioLLM/SenseVoiceSmall`）。
- ffmpeg 也用留影自带的 `bin/ffmpeg.exe`（只在非 silk 格式需要转码时用到）。
- 海螺自己可以覆盖（留空 = 跟随留影）：

```json
"asr": {
  "enabled": true,
  "base_url": "", "model": "", "api_key": "", "ffmpeg": "",
  "concurrency": 2
}
```

## 并发

- 单模型并发，不是多模型：同时最多 `concurrency`（默认 2）条语音在转，多的排队。
- 实测：单条 **1.0–1.7s**（下载 ~270ms + silk 解码 ~100ms + ASR ~1.0s）；3 条同时 **~2.2s**。
- 顺序：`await 转写` 之后才把消息交给合流器，**不会抢答**，一定是"先听完再开口"。

## 别把转写当原话（重要）

转写是机器听的，一定有错字。设计上分三层：

1. **标记**：正文前缀 `[语音转写] `，她一眼知道这不是对方一字不差说的。
2. **规则**：写进人设提示（每轮一句，不往每条消息后面追，省上下文）：
   > 带「语音转写」的消息是机器听出来的，可能有错字：按上下文顺着理解（名字、常用词明显听错的，
   > 按对的理解），别把错字当原话；但顺字不能改意思，时间、数字、要做的事拿不准就问一句。
3. **记忆库**：`content` 同样带 `[语音转写]`，`note` 写「语音转写，可能不准」，翻旧账时也分得清。

**不做**：同一段音频用同一个模型跑两遍对比（结果几乎一样，纯浪费）。异质模型（SenseVoice + whisper）
二意见能提升准确率，但多 1–2 秒、多花钱，目前没上。

## 失败策略

- 没配 ASR、下载失败、silk 解不出来、接口报错 → **当没听见**，不回、不写记录，绝不发半句乱码。
- 语音消息没有文字时才会去转写；纯图/表情走原来的逻辑。

## 试过但不用的

- **QQ 自带的语音转文字**（SnowLuma `fetch_ptt_text` → QQ 的 `pttTrans`）：
  老消息一律「语音转文字超时（未收到结果推送）」，SnowLuma 自己等 20 秒，拿不到字还拖时间 → 弃用。

## 测试

- `tests/test_memory_ingest.py`：语音入库的内容/标记/note、silk 魔数识别（含 `0x02` 前缀）、
  来源判断（本地文件 / url / 只有 id）、短标记不撑上下文、规则在人设提示里。
- 实测素材：群里 5 条真实语音，全部转出中文句子。
